# TCET Computer Engineering Department Website

A basic HTML website prototype created for deployment practice using Microsoft Azure Virtual Machine. The project presents information about the Computer Engineering Department at Thakur College of Engineering and Technology (TCET), including academics, faculty, infrastructure, and contact details.

## Technologies Used
- HTML5
- Microsoft Azure Virtual Machine

## Features
- Multi-section static webpage
- Department information layout
- Navigation menu
- Contact form structure
- Faculty and achievements sections

## Purpose
This project was developed to practice basic frontend development and website deployment using Azure Virtual Machines.
